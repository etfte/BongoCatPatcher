# BongoCatPatcher v3.0

Многофункциональная утилита с GUI и CLI для модификации и кастомизации игры Bongo Cat (Unity 6 Mono, Steam).

## Возможности

- **Графический интерфейс (GUI)**: Современный тёмный интерфейс на Windows Forms с индикатором статуса в реальном времени и управлением в один клик.
- **Автопоиск игры в Steam**: Автоматическое сканирование реестра Windows и всех библиотек Steam (`libraryfolders.vdf`) на любых дисках.
- **Полная разблокировка предметов**: Все шапки, скины, бонго, эмоции, темы интерфейса и секретные предметы становятся доступными.
- **Персистентность экипировки**: Выбранные скины сохраняются в `EQUIPPED_ITEMS_3` и не слетают при закрытии меню или перезапуске игры.
- **Разблокировка PawPass**: Активация бесплатной и премиальной дорожек наград всех сезонов пропуска лапок (`HasFreePass` и `HasPremiumPass`).
- **999 999 монет в копилке**: Увеличение отображаемых монет в `CoinStash`.
- **Защита от сброса эмоций**: Колесо эмоций `EmoteDonut` не очищается при валидации инвентаря.
- **Папка для кастомных скинов**: Автоматическое создание папки `Mods/Skins/` в каталоге игры.
- **Steam Update Guardian (`--watch`)**: Фоновый мониторинг файла `Assembly-CSharp.dll` с автоматическим повторным применением патча после обновлений игры в Steam.
- **Резервное копирование и откат**: Создание бэкапа перед патчем и возможность вернуть оригинальную сборку в любой момент.

## Использование

### Графический интерфейс (GUI)
Просто запустите `BongoCatPatcher.exe` двойным кликом (или командой `dotnet run` без параметров):
- Утилита автоматически найдёт путь к игре.
- Отобразит текущий статус сборки.
- Позволит в один клик применить патч, откатить изменения или открыть папки игры и модов.

### Командная строка (CLI)

```text
Опции:
  --gui, -g            Открыть графический интерфейс (по умолчанию при двойном клике)
  --cli                Принудительный запуск в режиме командной строки
  -p, --path <путь>    Указать путь к папке игры или к Assembly-CSharp.dll вручную
  -s, --status         Проверить статус сборки
  -r, --restore        Восстановить оригинальную сборку из бэкапа
  -w, --watch          Запустить Steam Update Guardian (авто-патч при обновлениях Steam)
  -h, --help           Показать справку
```

**Примеры:**
```bash
# Применить полный патч в консоли
dotnet run -- --cli

# Проверить статус сборки
dotnet run -- --cli --status

# Запустить защиту от обновлений Steam в фоне
dotnet run -- --cli --watch

# Откатить изменения к оригинальной версии
dotnet run -- --cli --restore
```

## Что изменяется в сборке

1. `BongoCat.SteamItemRuntime.get_IsOwned()` -> возвращает `true` (все предметы открыты).
2. `BongoCat.SteamItemRuntime.get_IsHiddenInInventory()` -> возвращает `false` (ничего не скрыто).
3. `BongoCat.ItemCollection.IsRevealed(...)` -> возвращает `true` (событийные скины видимы).
4. `BongoCat.CatCosmetics.EquipItem(...)` -> сохраняет экипировку в постоянный список `EQUIPPED_ITEMS_3`.
5. `BongoCat.CatCosmetics.Validate()` -> предотвращает очистку некупленных скинов при обновлении инвентаря.
6. `EmoteDonut.Validate()` -> защищает назначенное колесо эмоций от очистки.
7. `BongoCat.PawPass.PawPassEntity.get_HasFreePass()` -> возвращает `true`.
8. `BongoCat.PawPass.PawPassEntity.get_HasPremiumPass()` -> возвращает `true`.
9. `BongoCat.CoinStash.Refresh()` -> устанавливает 999 999 монет в копилке.
