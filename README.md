# BongoCatPatcher v4.0

Комплексный инструмент модификации Bongo Cat (Unity 6 Mono, Steam) с внутриигровым меню, графическим интерфейсом и CLI.

## Возможности v4.0

- **Внутриигровое меню настроек (In-Game Mod Menu)**:
  - Вызывается прямо в игре клавишами `F1`, `Insert` или `F8`, а также кнопкой `🐱 MOD MENU` в правом верхнем углу экрана.
  - Оформлено в фирменном пастельно-фиолетовом стиле Bongo Cat.
  - Позволяет на лету переключать разблокировку скинов, персистентность, PawPass, монеты и лимит кадров.
  - Все тумблеры автоматически сохраняются в реестре `PlayerPrefs`.
- **Графический интерфейс рабочего стола (WinForms Desktop GUI)**:
  - Управление в один клик: применить патч, откатить изменения, открыть папки игры, скинов и звуков.
  - Индикатор статуса сборки в реальном времени.
  - Сворачивание в системный трей Windows (Tray Minimization) с контекстным меню.
- **Steam Update Guardian (`--watch`)**:
  - Фоновый мониторинг `Assembly-CSharp.dll` через `FileSystemWatcher`.
  - Автоматическое повторное наложение патчей при обновлении игры в Steam.
- **Автопоиск игры в Steam**:
  - Сканирование реестра Windows и всех файлов `libraryfolders.vdf` на любых накопителях.
- **Полная разблокировка предметов и персистентность**:
  - Все шапки, скины, бонго, эмоции и секретные предметы доступны сразу.
  - Выбранные аксессуары сохраняются в `EQUIPPED_ITEMS_3` и не слетают при перезапуске.
- **PawPass Unlock (Боевой пропуск)**:
  - Разблокированы бесплатные и премиальные дорожки наград (`HasFreePass` и `HasPremiumPass`).
- **999 999 монет в копилке (Coin Stash)**:
  - Увеличен баланс монет для отображения и крафта.
- **Поддержка кастомных текстур и звуков**:
  - Папка `Mods/Skins/` для пользовательских PNG-спрайтов.
  - Папка `Mods/Sounds/` для пользовательских аудиоклипов нажатий лапками.
- **Лимит FPS (Frame Rate Limiter)**:
  - Выбор режима в меню: `По умолчанию`, `60 FPS`, `120 FPS`, `144 FPS`, `240 FPS`, `Без ограничений`.

## Использование

### 1. Запуск через графический интерфейс (GUI)
Запустите `BongoCatPatcher.exe` двойным кликом:
- Программа автоматически найдёт Bongo Cat.
- Нажмите кнопку **«🚀 Применить патч v4.0»**.
- Запустите игру в Steam.
- В игре нажмите **F1** для открытия внутриигрового меню!

### 2. Командная строка (CLI)

```text
Опции:
  --gui, -g            Запустить графический интерфейс (по умолчанию при двойном клике)
  --cli                Принудительный консольный режим
  -p, --path <путь>    Указать путь к папке игры или к Assembly-CSharp.dll вручную
  -s, --status         Проверить статус сборки
  -r, --restore        Восстановить оригинальную сборку из бэкапа
  -w, --watch          Запустить Steam Update Guardian (авто-патч при обновлениях Steam)
  -h, --help           Показать справку
```

**Примеры команд:**
```bash
# Применить полный патч v4.0 в консоли
dotnet run -- --cli

# Проверить статус сборки
dotnet run -- --cli --status

# Запустить мониторинг обновлений Steam в фоне
dotnet run -- --cli --watch

# Откатить сборку к оригинальному состоянию
dotnet run -- --cli --restore
```

## Управление внутриигровым меню

| Клавиша / Кнопка | Действие |
|---|---|
| **F1**, **Insert**, **F8** | Открыть / закрыть меню настроек прямо в игре |
| **Кнопка `🐱 MOD MENU`** | Переключение меню мышью в правом верхнем углу |
| **Тумблеры `[✔]`** | Включение / выключение функций в реальном времени |
| **Кнопки FPS** | Мгновенное переключение лимита кадров (60 / 144 / 240 / Макс) |
