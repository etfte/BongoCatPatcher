# BongoCatPatcher

Утилита с GUI и CLI для модификации и кастомизации игры Bongo Cat (Unity 6 Mono, Steam).

## Возможности

- **Полная разблокировка предметов**: Все шапки, скины, бонго, эмоции, темы интерфейса и секретные предметы доступны сразу.
- **Персистентность экипировки**: Выбранные аксессуары сохраняются в `EQUIPPED_ITEMS_3` и не сбрасываются при перезапуске.
- **Разблокировка PawPass**: Активация бесплатной и премиальной дорожек наград всех сезонов пропуска лапок (`HasFreePass` и `HasPremiumPass`).
- **Чистый оригинальный интерфейс игры**: Никаких модовых меню, лишних кнопок или оверлеев в окне Bongo Cat — интерфейс остаётся 100% оригинальным.
- **Настоящая внутриигровая экономика**: Баланс монет и игровой кошелёк не модифицируются (без фейковых денег и накрутки).
- **Папка для кастомных скинов**: Поддержка подмены спрайтов через папку `Mods/Skins`.
- **Steam Update Guardian (`--watch`)**: Фоновый мониторинг `Assembly-CSharp.dll` для восстановления патча в случае обновления игры в Steam.

---

## Использование

### 1. Графический интерфейс (GUI)
Запустите `BongoCatPatcher.exe` с Рабочего стола или из папки:
- **«🎮 Запустить Bongo Cat»** — быстрый запуск игры.
- **«🚀 Применить патч»** — разблокировка всех предметов и PawPass.
- **«🔄 Восстановить»** — мгновенный возврат к чистой оригинальной игре из бэкапа.
- **«⚡ Интеграция в Steam»** — удобный запуск через клиент Steam.
- **«🛡️ Защита Steam»** — включение фонового мониторинга.

### 2. Командная строка (CLI)

```text
Опции:
  --gui, -g                 Открыть графический интерфейс (по умолчанию при даблклике)
  --cli                     Принудительный запуск в консоли
  -l, --launch              Запустить Bongo Cat напрямую
  --steam-launch <exe>      Режим запуска для Steam Launch Options
  --install-steam-hook      Привязать запуск через утилиту в Steam
  --remove-steam-hook       Удалить привязку из Steam
  -p, --path <путь>         Указать путь к папке игры или к Assembly-CSharp.dll вручную
  -s, --status              Проверить статус сборки и хука Steam
  -r, --restore             Восстановить оригинальную сборку из бэкапа
  -w, --watch               Запустить Steam Update Guardian (фоновый мониторинг)
  -h, --help                Показать справку
```

**Примеры команд:**
```bash
# Проверить статус сборки
BongoCatPatcher.exe --cli --status

# Восстановить оригинальную чистую игру
BongoCatPatcher.exe --cli --restore

# Применить чистый патч разблокировки
BongoCatPatcher.exe --cli
```
