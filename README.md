# BongoCatPatcher v2.0

Утилита на базе .NET и Mono.Cecil для статического патчинга сборки `Assembly-CSharp.dll` игры Bongo Cat (Unity 6 Mono).

## Возможности

- **Автопоиск игры**: Автоматически сканирует реестр Windows и все библиотеки Steam (`libraryfolders.vdf`) на всех дисках.
- **Полная разблокировка**: Открывает все шапки, скины, бонго, эмоции и скрытые/событийные предметы.
- **Персистентность (сохранение экипировки)**: Устранена проблема сброса скинов при закрытии меню или перезапуске клиента.
- **Защита колеса эмоций**: Эмоции в быстром доступе не слетают при фоновой валидации инвентаря.
- **Резервное копирование и откат**: Автоматическое создание бэкапа перед патчем и восстановление одной командой.
- **Проверка статуса**: Отображение текущего состояния сборки (чистая / пропатченная).

## Использование

### Быстрый запуск
Запустите патчер без аргументов — он сам найдёт игру, создаст резервную копию и применит изменения:
```bash
dotnet run
```

### Команды и параметры

```text
Опции:
  -p, --path <путь>    Указать путь к папке игры или к Assembly-CSharp.dll вручную
  -s, --status         Проверить статус сборки (пропатчена или оригинальная)
  -r, --restore        Восстановить оригинальную сборку из бэкапа
  -h, --help           Показать справку
```

**Примеры:**
```bash
# Проверить статус сборки
dotnet run -- --status

# Откатить изменения к оригинальной версии
dotnet run -- --restore

# Указать нестандартный путь
dotnet run -- -p "D:\Games\BongoCat"
```

## Что модифицируется в сборке

1. `BongoCat.SteamItemRuntime.get_IsOwned()` -> возвращает `true`.
2. `BongoCat.SteamItemRuntime.get_IsHiddenInInventory()` -> возвращает `false`.
3. `BongoCat.ItemCollection.IsRevealed(...)` -> возвращает `true`.
4. `BongoCat.CatCosmetics.EquipItem(...)` -> сохраняет предметы в постоянный список `EQUIPPED_ITEMS_3`.
5. `BongoCat.CatCosmetics.Validate()` -> защищает экипировку от удаления при обновлении инвентаря.
6. `EmoteDonut.Validate()` -> защищает назначенные эмоции от сброса.
