# BongoCatPatcher v3.1

Многофункциональная утилита с GUI и CLI для модификации и кастомизации игры Bongo Cat (Unity 6 Mono, Steam) с автоматической проверкой обновлений при запуске игры и самообновлением с GitHub.

## Возможности v3.1

- **Авто-проверка обновлений при запуске игры**:
  - При запуске Bongo Cat (из Steam или по ярлыку) утилита мгновенно проверяет, не обновилась ли игра в Steam.
  - Если игра обновилась, патч автоматически подтягивает обновления с GitHub, адаптируется и перепатчивает сборку под новую версию без необходимости что-либо нажимать вручную!
- **Бесшовная интеграция в Steam (Steam Launch Hook)**:
  - Управление параметром запуска Steam в один клик: нажатие «Играть» в самом клиенте Steam автоматически запускает авто-проверку и бесшовно открывает игру.
- **Самообновление с GitHub (`GitHubUpdater`)**:
  - Утилита связывается с репозиторием `etfte/BongoCatPatcher` и проверяет наличие свежих релизов и определений патчей.
  - Офлайн-устойчивость: таймаут 2-3 секунды гарантирует, что игра всегда запустится мгновенно даже без подключения к интернету.
- **Чистый оригинальный интерфейс игры**:
  - Никаких визуальных меню, лишних кнопок или оверлеев в самом окне Bongo Cat — интерфейс игры остаётся 100% аутентичным.
- **Полная разблокировка предметов**: Все шапки, скины, бонго, эмоции, темы интерфейса и секретные предметы доступны сразу.
- **Персистентность экипировки**: Выбранные аксессуары сохраняются в `EQUIPPED_ITEMS_3` и не слетают при перезапуске.
- **Разблокировка PawPass**: Активация бесплатной и премиальной дорожек наград всех сезонов пропуска лапок (`HasFreePass` и `HasPremiumPass`).
- **Полностью функциональные монеты и магазин (Рабочая экономика)**:
  - Реальный динамический локальный кошелёк с сохранением в `PlayerPrefs` (`LOCAL_BONGO_COINS`).
  - Активная покупка предметов за монеты в магазине поддержки (Supporter Shop): кнопка покупки всегда активна, анимация летающих монет, плавный DOVirtual-отсчёт списания баланса, анимация покупки и зачисление предметов в инвентарь и статистику достижений.
  - Мгновенное открытие сундуков без зависаний: обход серверного ожидания токенов Steam в `ChestExchanger`, генерация случайных наград из каталога, фанфары и авто-экипировка.
  - Поддержка открытия дверей рождественского адвент-календаря (`AdventsDrawer`).
- **Steam Update Guardian (`--watch`)**: Фоновый мониторинг `Assembly-CSharp.dll` в реальном времени.

## Использование

### 1. Графический интерфейс (GUI)
Запустите `BongoCatPatcher.exe` с Рабочего стола или из папки:
- **«🎮 Запустить Bongo Cat (с авто-проверкой)»** — проверяет игру, обновляет патч и запускает кота.
- **«⚡ Авто-патч в Steam»** — привязывает авто-проверку к кнопке «Играть» прямо в Steam.
- **«🌐 Обновления GitHub»** — ручная проверка свежих версий на GitHub.
- **«🚀 Применить патч»** и **«🔄 Восстановить»** — ручное управление сборкой.

### 2. Командная строка (CLI)

```text
Опции:
  --gui, -g                 Открыть графический интерфейс (по умолчанию при даблклике)
  --cli                     Принудительный запуск в консоли
  -l, --launch              Запустить Bongo Cat с авто-проверкой обновлений
  --steam-launch <exe>      Режим авто-проверки и запуска для Steam Launch Options
  --install-steam-hook      Автоматически привязать авто-патч к кнопке «Играть» в Steam
  --remove-steam-hook       Удалить привязку из Steam
  --update-check            Проверить обновления патчера на GitHub
  -p, --path <путь>         Указать путь к папке игры или к Assembly-CSharp.dll вручную
  -s, --status              Проверить статус сборки и хука Steam
  -r, --restore             Восстановить оригинальную сборку из бэкапа
  -w, --watch               Запустить Steam Update Guardian (фоновый мониторинг)
  -h, --help                Показать справку
```

**Примеры команд:**
```bash
# Запустить игру с авто-проверкой и патчем
dotnet run -- --launch

# Привязать авто-патч к кнопке «Играть» в клиенте Steam
dotnet run -- --install-steam-hook

# Проверить статус сборки и Steam-хука
dotnet run -- --cli --status

# Проверить обновления на GitHub
dotnet run -- --update-check
```
